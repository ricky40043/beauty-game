# 💄 今日我最美

掃 QR code 就能玩的拍照派對遊戲。主畫面開在電視或筆電，大家用手機拍照比美。

## 玩法

1. 房主開房 → 主畫面顯示 6 碼房號與 QR code
2. 玩家掃碼入場（**預設不用取名**，系統自動配「🦦 害羞的水獺」這類暱稱，大廳可自己改）
3. 每一題出現在手機**最上方**，馬上開相機拍照上傳
4. 照片一送出就**彈到主畫面正中央**，停 3 秒淡出；連拍時新照片直接蓋在舊的上面
5. 主畫面下方常駐**最快交卷的前 5 張**縮圖，可點開放大
6. 收桌後房主從所有投稿裡選 **1~5 張**得獎，點選順序就是名次
7. 跑完所有題目 → 排行榜 + 本場得獎照片牆

## 兩種模式

| | 單人 | 團體 |
|---|---|---|
| 題目 | 表情、模仿、自拍姿勢、找顏色、找物品、進階構圖 | 需要多人一起入鏡的合體照 |
| 上傳 | 每人一張（可重拍覆蓋） | 任何人都能代表全場，每人最多 3 張 |
| 收桌 | 全員交卷即提前收桌 | 由房主按「提前結束拍照」或等倒數 |
| 得分 | 得獎者本人加分 | 拍攝者拿名次分，**全場每人再 +50 合作分** |

## 出題方式

- **隨機抽題**：設定題數（1~30）與難度（只出基礎題 / 基礎+進階混合）
- **自選題目與順序**：從題庫裡挑，可上下排序、可自己加題，**清單順序就是出題順序**；進大廳後還能再編輯

內建 75 題（單人 50、團體 25）。到 `/admin` 可以**新增自己的題目**、修改、刪除，
也可以把不想出現的內建題**停用**。新增的題目立刻進入題庫，之後開的房間就抽得到。

## 題目示範圖

團體題（25 題）在**主畫面正中央**會顯示參考站位圖，讓大家一眼知道要怎麼站。手機端維持只顯示題目文字，不佔用相機畫面。

- **內建圖**：程式即時畫出來的火柴人 SVG，內嵌在執行檔裡、不外連、無版權疑慮
- **自訂圖**：到 `/admin` 可以幫任何一題上傳自己的圖（PNG / JPEG / WebP / SVG，4MB 內），會蓋掉內建圖，隨時可還原
- 新增的自訂題目一樣可以上傳示範圖

> 沒有從網路抓任何圖片。動漫、藝人等素材有版權，抓下來打包進會對外部署的 App 就是侵權，所以內建圖一律自己畫。想用別的圖請自行從後台上傳，內容責任在上傳者。

後台預設不設密碼（本機方便）。對外部署請務必設 `ADMIN_TOKEN` —— **知道這組密碼的人都能新增題目、換圖**，不知道的一律 401。

自訂題目（`questions.json`）與自訂圖都存在 `EXAMPLE_DIR`（預設 `backend/data/examples`）。**容器化部署的磁碟是暫時的**，重新部署後自訂圖會消失，要長期保留請掛持久磁碟或改接物件儲存。

## 計分

| 項目 | 分數 |
|---|---|
| 完成上傳 | +10 |
| 抵達順序前三 | +15 / +10 / +5 |
| 得獎（依名次） | 100 / 80 / 60 / 40 / 20 |
| 團體合作分（該回合有得獎時全場都拿） | +50 |

## 本機開發

```bash
./start.sh
```

- 主畫面 → http://localhost:3344
- 手機測試 → 用同網段 IP 連 `http://<你的IP>:3344`

需要 Go 1.21+ 與 Node 18+。不需要資料庫或 Redis。

### ⚠️ 手機測試的相機

`getUserMedia`（網頁內即時相機）只在 **HTTPS 或 localhost** 可用。手機用區網 IP 走 http 連進來時瀏覽器會擋掉，App 會**自動退回「開啟系統相機」**，拍照上傳流程一樣完整，只是少了頁面內的即時預覽。正式部署走 HTTPS 就沒這個問題。

## 部署

### 地端 server（主要方式）

GitHub Actions self-hosted runner + Docker Compose + Cloudflare Tunnel，**防火牆一個 port 都不用開**，而且拿得到合法 HTTPS（手機的網頁內即時相機才能用）。

推上 `main` → GitHub 雲端跑測試 → 通過才輪到你的 server 重建重啟。

完整步驟見 **[docs/地端部署指南.md](docs/地端部署指南.md)**。

```bash
# server 上只要準備好 /opt/beauty-game/.env，之後都交給 CI
docker compose --env-file /opt/beauty-game/.env up -d --build
```

自訂示範圖存在 named volume，重新部署不會消失。

### 其他方式

單一 Docker image，前後端合一：

```bash
docker build -t beauty-game .
docker run -p 8081:8081 -e FRONTEND_URL=https://你的網域 -e ADMIN_TOKEN=... beauty-game
```

`render.yaml` 也還留著，可直接開 Render Blueprint。build 階段會先跑 Go 測試，沒過就不會產生映像。

`FRONTEND_URL` 決定 QR code 指向哪個網址，部署時一定要設對。

## 隱私

照片**只存在伺服器記憶體**，不落地、不進資料庫。房間結束、房主開新一局、或閒置 2 小時被清理時，該房所有照片會整批釋放。服務重啟照片也會全部消失。

## 技術架構

- **後端**：Go 1.21 + Gin + Gorilla WebSocket，純記憶體狀態
- **前端**：Vue 3 + TypeScript + Vite + Pinia + TailwindCSS
- **照片**：前端 canvas 壓縮（長邊 1080px / JPEG 0.75）→ HTTP multipart 上傳 → WebSocket 只傳 photoId

詳細架構與協定見 [CLAUDE.md](CLAUDE.md)。
