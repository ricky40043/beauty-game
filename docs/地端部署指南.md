# 地端 server 部署指南

把「今日我最美」部署到自己家裡/公司的 server，用 GitHub Actions 自動 CI/CD，並透過 Cloudflare Tunnel 拿到 HTTPS。

## 為什麼是這個組合

你的 server 在 NAT 後面、外網進不來。這帶來兩個問題，各自的解法是：

| 問題 | 解法 | 為什麼 |
|---|---|---|
| GitHub 連不進來，怎麼觸發部署？ | **self-hosted runner** | runner 裝在 server 上，**主動**向 GitHub 領工作，不需要對外開任何 port |
| 手機相機需要 HTTPS，但沒有固定 IP 和憑證 | **Cloudflare Tunnel** | `cloudflared` **主動**連出去，TLS 在 Cloudflare 終結。不用開 port、不用動態 DNS、不用自己續憑證 |

兩者都是「由內往外連」，所以你的防火牆一個洞都不用開。

> **HTTPS 為什麼重要**：`getUserMedia`（網頁內的即時相機）只在 HTTPS 或 localhost 可用。走 http 的話玩家會被退回「開啟系統相機」，能玩但少了頁面內即時預覽。有了 Cloudflare Tunnel 就是真正的 HTTPS，體驗完整。

## 架構

```
        GitHub                          你的 server（內網）
   ┌──────────────┐                ┌─────────────────────────────┐
   │ push to main │                │  self-hosted runner         │
   │      ↓       │◀──── 主動領工作 ─│      ↓ docker compose       │
   │ 跑測試(雲端)  │                │  ┌────────────┐             │
   └──────────────┘                │  │ app :8081  │             │
                                   │  └─────▲──────┘             │
   ┌──────────────┐                │        │ http://app:8081    │
   │  Cloudflare  │◀──── 主動連線 ───│  ┌─────┴──────┐             │
   │  (TLS 終結)   │                │  │ cloudflared│             │
   └──────▲───────┘                │  └────────────┘             │
          │ https                  └─────────────────────────────┘
      玩家手機
```

## 一、Server 前置準備

### 1. 安裝 Docker

```bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER    # 讓自己不用 sudo 也能跑 docker
# 重新登入讓群組生效
```

確認可用：

```bash
docker version && docker compose version
```

### 2. 建立部署目錄與設定檔

```bash
sudo mkdir -p /opt/beauty-game
sudo chown $USER:$USER /opt/beauty-game
```

產生一組後台密碼：

```bash
openssl rand -base64 24
```

建立 `/opt/beauty-game/.env`（**這個檔案只存在 server 上，不進 GitHub**）：

```bash
cat > /opt/beauty-game/.env <<'EOF'
FRONTEND_URL=https://game.你的網域.com
ADMIN_TOKEN=剛剛產生的那串
CLOUDFLARE_TUNNEL_TOKEN=待會從 Cloudflare 拿
EOF

chmod 600 /opt/beauty-game/.env
```

> 機密放在 server 的 `.env`、不放 GitHub Secrets，是刻意的：CI 只負責「重建並重啟」，完全不需要知道密碼是什麼，洩漏面比較小。

## 二、Cloudflare Tunnel

1. 進 [Cloudflare Zero Trust](https://one.dash.cloudflare.com/) → **Networks** → **Tunnels** → **Create a tunnel**
2. 類型選 **Cloudflared**，取個名字（例如 `beauty-game`）
3. 建立後它會給你一段安裝指令，裡面 `--token` 後面那串就是 token
   → 把它填進 `/opt/beauty-game/.env` 的 `CLOUDFLARE_TUNNEL_TOKEN`
   （**不用**照它的指令安裝，我們用 docker compose 跑）
4. 切到 **Public Hostname** 分頁，新增一筆：

   | 欄位 | 值 |
   |---|---|
   | Subdomain | `game`（或你想要的） |
   | Domain | 你在 Cloudflare 的網域 |
   | Service Type | `HTTP` |
   | URL | `app:8081` |

   > `app` 是 docker compose 裡的服務名稱，cloudflared 在同一個網路裡靠這個名字找到它。

5. 確認 `FRONTEND_URL` 跟這裡設的 hostname 一致（例如 `https://game.你的網域.com`）

### WebSocket 要確認打開

這個遊戲整個靠 WebSocket 運作。Cloudflare 所有方案預設都支援，但還是去確認一下：
**Cloudflare Dashboard → 你的網域 → Network → WebSockets** 是 **On**。

## 三、裝 GitHub Actions self-hosted runner

在 repo 頁面：**Settings → Actions → Runners → New self-hosted runner**，選 Linux，照畫面指令做。大致是：

```bash
mkdir -p ~/actions-runner && cd ~/actions-runner
# 下載那兩行指令直接複製 GitHub 給你的（版本號會變）
./config.sh --url https://github.com/ricky40043/beauty-game --token <GitHub 給的 token>
```

裝成開機自動啟動的服務：

```bash
sudo ./svc.sh install
sudo ./svc.sh start
sudo ./svc.sh status
```

回到 **Settings → Actions → Runners**，狀態應該是綠色的 **Idle**。

### runner 要能跑 docker

runner 是用你的帳號跑的，確認那個帳號在 `docker` 群組裡：

```bash
groups | grep docker || sudo usermod -aG docker $USER
# 加完要重啟 runner 服務才會吃到新群組
sudo ~/actions-runner/svc.sh stop && sudo ~/actions-runner/svc.sh start
```

## 四、部署

推上 `main` 就會自動跑：

```bash
git push origin main
```

流程是：

1. **GitHub 雲端機器**跑 Go 測試、gofmt 檢查、前端型別檢查與建置
2. 全部通過才輪到**你的 server**：`docker compose build` → `up -d`
3. 等健康檢查通過（最多 60 秒），失敗會印出容器日誌
4. 清掉舊 image

測試沒過就不會碰你的 server。

也可以到 **Actions** 分頁按 **Run workflow** 手動觸發。

### 第一次部署後確認

```bash
# 容器狀態
docker compose --env-file /opt/beauty-game/.env ps

# 健康檢查
docker exec beauty-game wget -qO- http://localhost:8081/api/health

# tunnel 有沒有連上
docker logs beauty-game-tunnel --tail 20
```

然後用手機開 `https://game.你的網域.com`，應該要看到首頁，而且網址列是鎖頭（不是「不安全」）。

## 五、日常維運

```bash
cd /path/to/beauty-game    # runner 的工作目錄，或你自己 clone 一份

# 看日誌
docker compose --env-file /opt/beauty-game/.env logs -f app

# 重啟
docker compose --env-file /opt/beauty-game/.env restart app

# 手動更新（平常交給 CI 就好）
git pull && docker compose --env-file /opt/beauty-game/.env up -d --build
```

### 自訂示範圖會保留

從 `/admin` 上傳的示範圖存在 named volume `example-images`，**重新部署不會消失**（這是地端部署比 Render 好的地方之一）。

備份：

```bash
docker run --rm -v beauty-game_example-images:/data -v $(pwd):/backup \
  alpine tar czf /backup/examples-backup.tar.gz -C /data .
```

### 玩家照片依然不落地

玩家拍的照片只存在記憶體，房間結束、重開一局、或閒置兩小時清理時就整批釋放。容器重啟也會全部消失。這是刻意的設計，跟示範圖不同。

## 六、安全檢查清單

部署完對外之前，確認：

- [ ] `ADMIN_TOKEN` 有設而且夠長 —— **沒設的話任何人都能改你的示範圖**
- [ ] `/opt/beauty-game/.env` 權限是 `600`
- [ ] `FRONTEND_URL` 跟 Cloudflare 的 hostname 完全一致（含 `https://`，結尾不要斜線）
- [ ] Cloudflare 的 WebSockets 是 On
- [ ] 手機實測：能掃 QR 進場、能開網頁內相機（不是退回系統相機）

想再加一層保護的話，Cloudflare Zero Trust 可以在 tunnel 前面加 Access 政策，限定只有特定 email 或網段能進。

## 常見狀況

| 症狀 | 原因 | 處理 |
|---|---|---|
| 手機掃 QR 連不上 | `FRONTEND_URL` 沒設成正式網址 | 改 `.env` 後重新部署 |
| 網頁內相機開不了，一直是「開啟系統相機」 | 沒走到 HTTPS | 確認網址是 `https://`、Cloudflare proxy（橘色雲）是開的 |
| 進得去但一直「連線中斷，重試中」 | WebSocket 被擋 | 檢查 Cloudflare 的 WebSockets 開關；確認 Public Hostname 的 URL 是 `app:8081` |
| Actions 卡在 `deploy` 排隊 | runner 離線 | `sudo ~/actions-runner/svc.sh status`，必要時 `start` |
| 部署失敗說找不到 `.env` | server 上還沒建設定檔 | 照上面「二、1」建立 `/opt/beauty-game/.env` |
| 後台上傳圖回 401 | `ADMIN_TOKEN` 有設但前端沒填 | 開 `/admin`，在密碼欄輸入同一組 token |
