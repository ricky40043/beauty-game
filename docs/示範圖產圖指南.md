# 題目示範圖 — 產圖指南

給「今日我最美」的團體題製作參考站位圖。你可以用 AI 產圖、自己拍、或找圖，做好後放進指定位置就會自動生效。

## 1. 檔案要放哪裡

```
/Users/ricky/Desktop/beauty-game/backend/data/examples/
```

檔名就是**題號**加副檔名：

```
2001.png
2004.jpg
2009.webp
2021.svg
```

支援 `png` / `jpg` / `webp` / `svg` 四種。

### ⚠️ 一題只能放一個檔案

同一個題號**不要同時**放 `2001.png` 和 `2001.jpg`。程式讀取時是依 `jpg → png → webp → svg` 的順序找第一個存在的檔案，兩個都在會拿到你沒預期的那張。

要換格式請先把舊的刪掉。（從 `/admin` 網頁上傳則會自動處理，不會有這問題。）

### 兩種放法

| 方式 | 做法 |
|---|---|
| **直接丟檔案** | 把圖複製到上面那個資料夾，檔名取對即可 |
| **網頁上傳** | 開 `/admin`，找到題目按「上傳圖片」，會自動存到同一個資料夾 |

兩種都**不需要重開服務**。丟完檔案後最多一分鐘瀏覽器就會換成新圖（想立刻看到就 `Cmd + Shift + R` 強制重新整理）。

## 2. 圖片規格

| 項目 | 建議 |
|---|---|
| 比例 | **16:9 橫式**（畫面是橫的大螢幕） |
| 尺寸 | 1280×720 就夠，最大不要超過 1920×1080 |
| 檔案大小 | 網頁上傳限 **4MB**；直接丟檔案沒限制，但別放太肥 |
| 背景 | **深色或透明**。主畫面底色是深藍黑（`#020617`），白底圖會變成一塊刺眼的亮方塊 |
| 文字 | **不要放文字**。題目本身已經用大字顯示在圖的上方了，AI 產的中文字通常也是亂碼 |
| 人數 | **3~5 人**，全身入鏡。人太多會看不出站位 |

圖片在畫面上最高佔 46% 螢幕高度、置中顯示，照片投稿彈出時會疊在它上面。

### 風格前綴（建議 A：插畫風，跟現有 UI 最搭）

```
flat vector illustration, minimal line art, light grey strokes on dark navy background,
16:9 landscape, centered composition, simple stick-figure style people, full body,
no text, no logos, clean and readable at a glance. Scene:
```

### 風格前綴（建議 B：真實照片風）

```
candid group photo, 3 to 5 people, full body visible, dark simple background,
16:9 landscape, natural lighting, no text, no watermark. Scene:
```

## 4. 做好之後怎麼確認

```bash
# 看某一題現在讀到的是哪張圖（builtin = 內建火柴人，custom = 你的圖）
curl -s -D- -o /dev/null http://localhost:8081/api/questions/2009/example | grep -i x-example-source
```

或直接開 `/admin`，那頁會列出每一題目前是 **自訂圖 / 內建圖 / 無**，並顯示縮圖。

想反悔就在後台按「還原內建」，或直接把檔案刪掉，內建的火柴人圖會自動接手。

## 5. 想加單人題也可以

單人題（題號 `1001`~`1508`）目前沒有內建圖，但一樣支援自訂圖 —— 檔名放對題號就會顯示。完整題號清單：

```bash
curl -s "http://localhost:8081/api/questions?mode=solo" | python3 -m json.tool
```
